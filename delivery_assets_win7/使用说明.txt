现代零售终端智慧运营平台（Windows 7 版）

一、适用系统
Windows 7 SP1 64 位、Windows 10 64 位、Windows 11 64 位。

二、使用方法
1. 先完整解压 ZIP 压缩包，不要直接在压缩包预览窗口中运行。
2. 双击“现代零售终端智慧运营平台_Windows7版.exe”。
3. 浏览器打开后，等待右上角显示“模型已就绪”。
4. 在五个检测项目中分别选择对应图片。
5. 可点击“检测此项”，也可点击顶部“检测全部”。
6. 检测完成后可保存结果图或导出 JSON 检测数据。

三、运行特点
模型、Python 3.8 运行时、ONNX Runtime、OpenCV、NumPy 和网页资源均已打入 EXE。
运行时无需安装 Python，无需配置开发环境，无需连接互联网。
图片和推理结果仅在本机处理，本地服务仅监听 127.0.0.1。

四、Windows 7 系统要求
系统应为 Windows 7 SP1 64 位，并建议安装现有 Windows 7 系统更新。
若系统长期未更新并提示系统组件缺失，请先通过微软官方渠道安装 Windows 7 SP1 及 KB2533623。

五、运行日志
日志位置：%LOCALAPPDATA%\ModernRetailTerminal\logs\application-win7.log
如需排查，请同时提供错误截图、Windows 版本和上述日志文件。
